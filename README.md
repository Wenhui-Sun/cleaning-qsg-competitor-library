# 清洁家电竞品物料图片库

这是一个面向产品体验、包装与说明书设计研究的竞品图片库，覆盖吸尘器、洗地机、布艺清洗机、扫地机器人和除螨仪。

- 在线网站：https://cleaning-qsg-competitor-library.wsun0414.chatgpt.site/
- 当前规模：318 份实物物料、371 张照片
- 主要品牌：Shark、Philips、Dreame、Roborock、Rowenta、Bissell、Tineco、Dyson，并包含 Hoover、Luwant、Yadea、IRIS OHYAMA、Simplus、PerySmith 等补充样本

## 仓库内容

| 路径 | 内容 |
| --- | --- |
| `dist/` | 可直接部署的静态网站、高清图片、缩略图和网站内图片索引 |
| `data/图片索引.csv` | 全库逐图索引，包含品牌、品类、型号、物料类型、语言、观察与来源 |
| `data/品类体验优化追踪图片分类.csv` | 《品类体验优化追踪.xlsx》中 74 张照片的逐张处理结果 |
| `docs/分类与入库规则.md` | 分类口径、合集规则、命名规则、排除规则及审核流程 |

## 使用方法

打开 `dist/index.html` 即可离线浏览。网站支持按照以下维度组合筛选：

1. 品牌
2. 品类
3. 物料类型

卡片以“一份实物物料”为单位。同一物料的不同角度或正反面照片显示为一个合集，点击主图后可以逐张查看。

## 数据说明

- 标签只显示品牌、品类和可确认的型号，不显示原始图片文件名。
- 设计分析描述版式、信息层级、图文关系、色彩和载体位置。
- 只有图片中文字清晰可辨时才记录语言；看不清的小字不推断。
- 品牌或型号以实物图片上可辨认的信息为优先依据，表格列标题和文件名只作为辅助线索。
- 研究图片来自品牌公开资料、公开商品与评测页面，以及用户提供的实物照片。图片权利归各自权利人所有，本仓库用于内部竞品研究与设计分析。

## 更新流程

1. 提取新文件中的图片并保留来源位置。
2. 逐张识别品牌、品类、型号和物料类型。
3. 按“一份实物物料”合并不同角度照片。
4. 补充设计排版分析与可辨识语言。
5. 去重并排除无目标物料信息的照片。
6. 更新图片索引，重新生成网站并检查图片链接。
