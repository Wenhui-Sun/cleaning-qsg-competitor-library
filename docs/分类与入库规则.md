# 分类与入库规则

## 1. 基本原则

图片库以“实物物料”为研究对象，而不是以“单张照片”为对象。品牌、品类、型号和物料类型确定后，同一份实物物料的不同角度、正反面、展开页或局部细节合并为一个合集。

识别优先级：

1. 实物图片上清晰可辨的品牌、型号和文字
2. 同组照片中能够互相验证的信息
3. 包装、铭牌或说明书中的型号
4. 原始表格标题、文件夹名和文件名

如果图片证据与表格标题冲突，以图片证据为准，并在分类清单中保留处理结果。

## 2. 品牌规则

- 使用产品或物料上实际展示的品牌名。
- 中英文品牌名统一为主要国际品牌写法，例如“石头”归为 `Roborock`。
- 图中出现新品牌时直接新增品牌，不强行归到现有品牌。
- 经销商、平台水印、运输标签和拍摄环境中的其他品牌不作为产品品牌。

## 3. 品类规则

| 品类 | 判断依据 |
| --- | --- |
| 吸尘器 | 以干式吸尘为主要任务的手持、立式或桶式设备 |
| 洗地机 | 同时执行地面吸污与湿洗，面向硬地板的设备 |
| 布艺清洗机 | 以喷液、刷洗、抽吸方式清洁地毯、沙发、织物或汽车座椅的设备 |
| 扫地机器人 | 自主移动清扫的机器人及其基站 |
| 除螨仪 | 面向床褥、沙发等织物表面的除螨或拍打吸尘设备 |

若物料属于专用耗材或附件，品类跟随其明确适配的主机。

## 4. 物料类型规则

### 4.1 彩箱

零售展示包装，通常具有大面积彩色印刷、产品渲染图、使用场景、卖点图标和品牌信息。箱面虽然可能印有操作步骤，但只要其主要任务仍是零售展示，主类型为彩箱；其中完整的操作指南区域可另裁切为“快速入门指南”。

### 4.2 黄箱

以牛皮纸本色为主要视觉的运输箱、简装零售箱或套箱。允许少量单色品牌、型号、产品线稿、物流图标或封箱色带。彩箱与黄箱并排出现在同一张照片时，按照片主视觉和可研究信息选择主类型；必要时裁切为两份物料。

### 4.3 快速入门指南

任何直接告诉用户如何快速安装、首次使用、加水、加清洁液、充电、联网、清洁或维护的物料均归入此类，包括：

- 独立纸卡、折页、卡纸
- 吊牌和配件说明牌
- 贴在机身上的安装或操作步骤标贴
- 印在包装外侧、内翻盖或内托上的步骤指南
- 引导至操作视频或 App 的二维码卡片

只含标题的完整说明书封面不作为快速入门指南；只有出现具体动作、步骤或明确操作入口时才收录。

### 4.4 贴纸

贴在机身、配件或基站上的 Tips、温馨提醒、维护提醒与警告标签。例如：

- 清洁滤网、清空污水箱、保持通风
- 禁止事项和安全警告
- 运输保护或拆除提示
- 简短的日常操作提醒
- 操作视频二维码提示

如果标贴包含完整的连续安装或使用步骤，归入“快速入门指南”。如果主要内容是型号和额定参数，归入“铭牌”。

### 4.5 铭牌

用于产品身份和法规合规的信息标签，通常包含：

- 品牌及产品名称
- 型号、Type 或 SKU
- 额定电压、功率、频率等参数
- 序列号、条码或二维码
- 制造商、产地、认证和回收标志
- 与法规相关的多语言安全文字

铭牌即使包含警告内容，仍以身份参数和认证信息为主，因此不归为普通贴纸。

### 4.6 清洁液

主机配套清洁液、浓缩液、去渍剂或双配方补充瓶及其标签，包括：

- 瓶身正面品牌、配方名和卖点
- 背面使用、稀释与安全说明
- 瓶盖上的稀释提示
- 正反面、侧面和喷头结构等不同角度

同一瓶清洁液的正反面合并为一个合集。不同配方或不同容量原则上分为不同物料；明确作为一个双配方系统共同使用时，可建立系统级合集。

## 5. 合集规则

合集边界为“一份实物物料”。以下照片应合并：

- 同一个箱体的正面、背面、侧面、顶面和开箱角度
- 同一张纸卡的正反面或展开页
- 同一枚贴纸的全景和细节
- 同一块铭牌的整体位置和文字特写
- 同一瓶清洁液的正面、背面和侧面

以下情况不应合并：

- 同一型号上的两枚不同贴纸
- 同型号的彩箱与外层黄箱
- 同一品牌不同配方的清洁液
- 同一型号但属于不同版本或不同市场的包装

一张照片同时包含多份独立物料时，可裁切为多个清晰的研究对象。裁切后每个对象建立独立合集，并保留原始照片的来源记录。

## 6. 标签与型号规则

前端卡片标签只显示：

1. 品牌
2. 品类
3. 型号或明确的产品／配方名称

不显示原始文件名、照片序号或拍摄渠道。型号不可辨认时使用清晰可确认的系列名；不得根据外观猜测型号。

## 7. 语言规则

- 只记录肉眼可清晰辨识的语言。
- 多语种并列时按实际可见情况列出，例如“英语、德语、法语”。
- 只有认证缩写、数字或无法确认的小字时，不填写语言。
- 不根据销售地区或品牌国籍推断语言。

## 8. 设计排版分析规则

每张照片的分析聚焦物料设计，不描述无关拍摄环境。优先说明：

- 主视觉与品牌／型号的位置
- 信息层级和阅读顺序
- 图标、步骤编号、箭头、二维码的用法
- 色彩如何区分功能或配方
- 图文比例与版面分区
- 物料在箱体、机身或基站上的触达位置
- 不同角度之间的信息分工

分析避免抄录大量小字，也不对无法辨认的内容作推断。

## 9. 排除规则

以下照片不导入：

- 只有整机外观且没有目标物料信息
- 说明书封面但没有快速操作步骤
- 包装内托、塑料袋或泡沫本身没有设计信息
- 完全重复的照片
- 严重模糊、遮挡或无法确定品牌／品类的照片
- 拍摄环境中无关的产品、人物或货架照片

若照片对同一物料的结构位置有补充价值，可作为合集中的辅助角度保留。

## 10. 入库检查清单

每次导入前确认：

- 品牌、品类、型号均有图片证据
- 物料类型符合上述定义
- 同一实物已合并，不同实物未误合并
- 重复照片已去除
- 语言只记录清晰可辨内容
- 设计分析描述物料而不是文件名或拍摄地点
- 高清原图和缩略图均可打开
- 图片索引与网页卡片数量一致
- 新品牌和新物料类型能出现在筛选栏
